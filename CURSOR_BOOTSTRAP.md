# Cursor bootstrap

Put these files at the root of the Cursor project:

- `PROJECT_SPEC.md` — product, architecture, data model, crawler and AI specification.
- `AGENTS.md` — hard engineering/product/data/security boundaries.

Recommended first instruction to Cursor:

> Read `AGENTS.md` and `PROJECT_SPEC.md` completely. Do not code yet. Inspect the repository and produce a concise implementation plan, proposed ERD, RLS strategy, crawler interface, environment-variable contract, and Slice 1 task list. Do not invent missing requirements. Stop after the plan and wait for approval.

The supplied source URLs from the original project discussion are recorded in `PROJECT_SPEC.md` as seed sources.
